## About the Project

This project is a Festival Access and Crowd Control System created using JavaScript.

The program uses attendee information to check ages, tickets, VIP access and spending. It also manages food vouchers, venue capacity and the festival closing countdown.

## Features

- View all attendees in the queue.
- Check if an attendee can enter the festival.
- Assign wristbands based on ticket type.
- Check VIP lounge access.
- Search for an attendee.
- Skip attendees without valid tickets.
- Calculate food vouchers based on spending.
- Calculate festival statistics.
- Find the biggest spender.
- Control venue capacity.
- Display the festival closing countdown.
- Use a menu to access different festival operations.

## What I Learned

While working on this project, I learned how to use arrays and objects to store attendee information. I also practised using loops to go through the data and conditions to decide what should happen to each attendee.

I understand better how `if`, `else if` and `else` work, and how a `switch` statement can handle different menu options. I also learned how `break` stops a loop and how `continue` skips an item and moves to the next one.

I also learned how to calculate totals and statistics from the data instead of entering the answers manually. This helps the program give updated results when attendee information changes.
